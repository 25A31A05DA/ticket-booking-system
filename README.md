# Ticket Booking System

A simple multi-page ticket booking website built with HTML, CSS, and JavaScript.
It includes a login page, booking page, and a success page that generates a random seat number.

## Features

1.Basic login validation (static username + password)

2.Seat booking button

3.Random seat number on success page

4.Clean UI with simple styling

5.Three separate HTML pages

6.Works in any modern browser

## Project Structure
index.html        → Login Page
booking.html      → Booking Page
success.html      → Confirmation Page
style.css         → Styling
script.js         → Logic (login + booking + seat number)

## How It Works

1.User enters username and password

2.On success → redirected to booking page

3.User clicks “Book Now”

4.Redirected to success page

5.Seat number is generated automatically
